About the Project

The Global Olympic Sports Performance Analysis project uses historical Olympic athlete and medal data to identify patterns in national performance, sports, medal types, seasons and athlete participation.


Tableau is used to transform the dataset into interactive visualizations and dashboards, while Flask provides a web interface for presenting the analysis in an accessible format.

Project Objectives

What this analysis aims to discover

🏆 Medal Performance

Identify countries and sports producing the highest number of Olympic medals.

📊 Sports Analysis

Analyze which sports contribute most to medal success and gold medal performance.

🌍 Global Participation

Explore Olympic participation across countries, seasons and gender categories.
